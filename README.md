# To Sushi Cumbres · Demo de concepto

Propuesta independiente de sitio web para To Sushi Cumbres, Monterrey. Incluye el catálogo de referencia con 105 fichas, filtros por categoría, rollos y pokes personalizables, tres ubicaciones y un carrito con edición. Los precios son de referencia y el botón de WhatsApp genera un mensaje simulado dentro de la página.

## Desarrollo

El sitio es estático. `index.html` contiene la estructura, `style.css` el diseño y `app.js` la navegación y el flujo del pedido. Los productos, precios y opciones están en `menu.js`. Las imágenes WebP están en `assets/` y las leyendas se configuran en `menu-photos.js`. Para previsualizarlo, sirve la carpeta con un servidor local y abre la página de inicio.

GitHub Pages publica directamente desde la raíz de la rama `main`.
