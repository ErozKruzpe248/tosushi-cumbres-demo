# To Sushi Cumbres · Demo de concepto

Propuesta independiente de sitio web para To Sushi Cumbres, Monterrey. Incluye una portada animada, promoción de referencia, menú con filtros, tres ubicaciones y un carrito con edición. Los precios son de muestra y el botón de WhatsApp genera un mensaje simulado dentro de la página.

## Desarrollo

El sitio es estático. `index.html` contiene la estructura, `style.css` el diseño y `app.js` el catálogo y el flujo del pedido. Las imágenes optimizadas están en `assets/`. Para previsualizarlo, sirve la carpeta con un servidor local y abre la página de inicio.

GitHub Pages publica directamente desde la raíz de la rama `main`.
